# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

**Gmail Digest** (`main.py`) — Fetches new emails via Gmail API, summarizes them with Claude, sends digest to Telegram. Designed to run as a cron job.

## Running

```bash
source .venv/bin/activate

# Run the digest pipeline
python main.py

# One-time OAuth setup (opens browser)
python setup_oauth.py
```

## Dependencies

```bash
pip install -r requirements.txt
```

## Architecture

Linear three-step flow driven by `main.py`:

1. **`gmail_client.py`** — OAuth2 auth via `token.json`, fetches emails since last run. Bodies truncated to 2000 chars.
2. **`summarizer.py`** — Sends emails to Claude Sonnet for markdown digest. Uses `anthropic` SDK.
3. **`telegram_sender.py`** — Posts digest via `requests.post`. Messages capped at 4096 chars (Telegram limit).

**Last-run tracking**: Timestamp stored in `~/.gmail_digest_last_run` (ISO format). Defaults to 24h ago on first run.

## Required Environment Variables

Defined in `.env` (loaded via `python-dotenv`):
- `ANTHROPIC_API_KEY` — Claude API key
- `TELEGRAM_BOT_TOKEN` — Telegram bot token from BotFather
- `TELEGRAM_CHAT_ID` — Target Telegram chat ID

## OAuth Tokens

- `token.json` — Gmail read-only. Generated by `setup_oauth.py`.
- Requires `credentials.json` (Google OAuth2 Desktop client, not committed).
